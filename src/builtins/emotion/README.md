# 情绪与见闻（qq-emotion）

独立可信原生插件，复用 SDK 的配置、作用范围、上下文和持久存储。新安装默认停用；没有已接收的聊天就没有观察结果，不生成演示心情。

启用后从指定群和私聊最近六小时的实际对话选择变化过的上下文，通过现有零工具会话返回结构化观察。记录心情、强度、简短可观察原因、说话人和真实消息 ID。强度随时间缓和，各聊天分别保留原因；其他群只接收整体心情，不接收原群的原因。

心情可影响日常回复、自动选表情、主动联系、群内主动发言，以及自主时间生成的文字。它是持久化的角色状态，不代表人类意识，也不暴露模型内部推理；目前没有额外控制语音韵律。

## 群聊见闻私聊

需要同时满足：

- 本插件启用，作用范围包含观察群与主人私聊。
- 自主时间的主动联系启用，并开启“允许群聊见闻私聊分享”。
- QQ 在线，框架没有暂停；发送继续遵循现有主动联系策略，自由模式沿用现有配置。

模型可以选择分享有趣事件或暂时没接上的交流，也可以什么都不分享。每条事件保存消息 ID 与有限来源快照，按来源和主题去重；发送前重新校验主人、范围、事件有效性。只有机器人发言至少两分钟后又有三条群友消息、且没有引用或提及回复，才允许描述“暂时没接上话”。普通冷场不算；后来有人接话会取消旧事件。这只是可观察信号，不能据此认定别人故意冷落。

事件进入已有主动联系队列，由宿主发送。结果保留 submitted / accepted / confirmed / unknown / failed 等真实状态，不能把已受理当作已读。认领后进程中断标记结果未知，不自动重发。控制台插件卡片可以查看真实心情和分享记录。

## 数据与停用

数据位于 `framework.pluginData['qq-emotion']`，由 SDK 写入，大小不超过 64 KiB。最多保存 16 个聊天心情、48 个观察游标和 32 条最近一天的分享记录；待分享超过六小时取消。插件停用或移出范围后停止观察、注入和分享；重新启用保留原数据。主人或机器人账号变化会隔离旧状态。

观察失败保留上次有效状态并显示错误，不把生成失败当作新心情。聊天文本与模型输出都是数据，不能扩充权限或直接调用发送接口。
