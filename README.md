## 核心与功能包

核心始终保留 OneBot 11 对接、事件监听、主人管理、受限 Agent、权限检查、资源服务、插件 SDK 与审计。AI 聊天、人设、入群欢迎、戳一戳互动和市场作为内置包独立启停、卸载和重新安装；卸载保留业务数据。

除内置包外，还有几个独立注册的可信原生功能包：**QQ 空间**、**联网查资料**、**表情包**、**群成员动态**。它们各自有设置页、作用范围与独立动作授权。

### 表情包（qq-sticker）

- **收藏**：把当前聊天某条消息里的图片收进表情库，可加名字、标签（最多 5 个）和“什么时候用”。
- **偷图**：别人发的表情也能收，来源记成 `stolen`，并保留原聊天类型。
- **检索 / 发送**：按标签或关键词找，按编号发回当前聊天；发送走受控资源，不暴露本机路径。
- **识别用途**：`explain` 会把**图片本身**交给模型（工具结果里带图片块），由模型看图判断场合，不做无依据的猜测。
- **联网查含义**：复用联网查资料包（`plugin.qq-web.search`）搜“是什么梗、什么场合用”；搜索不可用时明确报告失败，不编造含义。
- **存储**：图片按内容哈希存到 `<数据目录>/stickers/`，索引只有元数据；同一张图重复收藏不占两份空间，默认上限 300 张 / 200 MB。
- **权限**：`save`/`steal`/`send`/`list`/`explain` 需要主人逐项授权，`remove` 仅主人；依赖 `qq.media.receive` 与 `qq.image.send`，未启用时动作会明确拒绝。
- **自动收藏（可选，默认关闭）**：`autoSaveSent` 开启后，她联网搜到并发出的图会自动入库；`autoSaveIncoming` 开启后，作用范围内聊天收到的图片会自动入库（单条最多 3 张）。自动收藏是系统行为，不受工具授权限制，**不设每日配额**，只受表情库容量（默认 300 张 / 200 MB）约束；写库失败只记日志，不影响消息收发。

关闭 AI 聊天包后，主人管理和显式受限任务仍可用。人设包只提供提示词与绑定，不改变工具权限。

## 权限

- 主人 QQ 从可信部署环境迁移，并可在本机设置页修改。昵称、群管理员身份、转发内容和入群通知不能授予主人身份。
- 默认只启用 core.status。其他动作需要主人在“主人与权限”中逐项启用。
- AI 工具和插件动作默认仅主人可用，在私聊或已允许的群内按范围调用。普通用户可在回复白名单内聊天，但没有执行权限。
- 开放权限必须指定动作、用户、私聊/群范围、额度及可选到期时间。明确拒绝优先；头像、昵称和请求处理等主人专属动作不能下放。
- 通用系统命令、任意代码、本机文件和凭据访问、任意 MCP/子代理、踢人/封禁/授予管理员/退群、批量群发和原始 OneBot action 不提供授权入口。
- QQ 专用预设不挂载 DSH 开发工具，空允许列表过滤继承工具；最终执行守卫同时检查本轮身份、策略版本和动作可用性。单次审批不能解除核心禁止。
- 按聊天、发起用户、入口隔离 Agent。配置变化取消旧任务；执行前和发送前复核授权，到期、撤销、卸载后不沿用旧权限。

可信 DSH 宿主、操作系统管理员、网关和主人账号属于信任边界。原生插件是可信宿主代码；声明能力不是 JavaScript 沙箱。市场不加载外部 JavaScript。

## 设置

- **连接**：正向双向 WS、反向 WS、Token 与模型。
- **聊天**：私聊和群成员范围、群 @触发、分条方式与间隔。
- **监听**：私聊用户、群、通知和请求；未 @消息也可产生事件。
- **主人与权限**：主人、暂停、能力开关、安全查询共享、特殊范围与审计。
- **人设**：名称加一段完整提示词；仅在人设包开启时出现。
- **插件管理**：内置包、声明式扩展、已注册的可信原生包及自有市场。
- **运行状态**：连接、消息任务、过滤原因、日志及折叠的手动调试台。

监听范围、回复触发、执行权限分别设置。群回复还需开启群聊，同时命中用户/群白名单，并满足 @规则；只开启“响应 @”不会开启群聊。主人管理私聊始终保留。

## 直接使用

直接说“查一下这个群的资料”“把这个群名改成……”即可。模型只获得当前身份实际可用的工具，无需任何斜杠前缀。主人也可直接说“机器人状态”“暂停机器人”“恢复机器人”“关闭AI聊天”等进行核心管理。

群内修改默认作用于当前群，不必填写群号；仍须满足 QQ 平台权限。普通用户要使用查询，需要主人在“其他人的查询工具”逐项开放，插件还要设置生效范围。聊天白名单不会自动授予工具。

## OneBot 能力

共有 28 个核心明确动作，另有群成员包注册的 1 个动作，SDK 不暴露 raw action。

| 分类 | 动作 |
| --- | --- |
| 状态 | core.status、qq.login、qq.capabilities |
| 联系人/群 | qq.friends.list、qq.groups.list、qq.group.info、qq.members.list、qq.member.info |
| 消息 | qq.message.send、qq.message.get、qq.forward.get、qq.message.recall |
| 媒体 | qq.media.receive、qq.image.send、qq.audio.send、qq.video.send、qq.file.send；联网查资料包可搜索并发送已校验图片 |
| 资料 | qq.profile.avatar、qq.profile.nickname、qq.group.selfCard、qq.group.name |
| 请求/历史 | qq.request.decide、qq.history.get |
| 扩展 | qq.forward.send、qq.files.list、qq.poke、qq.announcements.list、qq.essence.list |

消息链支持文字、QQ 表情、@指定成员、引用及图片。撤回只允许当前聊天中框架最近两分钟发送的消息；查询只允许已观察到的当前聊天消息。合并转发内容始终视为不可信数据。

头像、昵称、文件和历史等扩展需要网关声明为 NapCat。底层适配已实现并通过模拟网关验证，未对真实 QQ 发送媒体、改资料或审批请求；各格式与 QQ 版本的实际支持需在明确目标下验收。语音识别、图片理解和业务玩法不属于传输层。

媒体先成为聊天/插件绑定的资源 ID。支持受控上传或从当前聊天收到的 HTTPS 媒体获取，最大 8 MiB、有效期一小时、最多 100 项；图片另限制尺寸与像素。禁止任意本机路径、私网/回环下载；HTTPS 下载验证并固定 DNS 解析地址，每次重定向重新验证。使用 Base64 传输，避免远程网关误读本机路径。

WS 支持 echo、心跳和账号绑定；反向支持 Universal 或分开的 API/Event 角色。ok 表示确认，async 表示受理，超时/断线可能结果未知。写操作不会因超时自动重发。

## 插件开发

市场支持 **API 2 声明式包**，只含 manifest.json 和 rules.json。规则可匹配固定命令、关键词、通知，动作可提供固定模板结果；不执行脚本、任意正则、Shell 或原始网关调用。

可信 DSH 原生插件通过 ctx.qqFramework.registerTrustedPackage 注册，得到事件、动作、独立存储与媒体服务；默认停用，仍需在设置页启用包并单独批准动作。发布的类型位于 src/sdk.d.ts，可通过 dsh-onebot-bridge/sdk 的 types 导出使用。

详细例子、权限关系和生命周期见项目内部文档。内置帮助与关键词示例已重写为 API 2。

运行 npm run build:market 生成 market-dist/index.json 及两个 ZIP。市场索引 schema 仍为 1，包 hostApiVersion 为 2；条目包含完整 manifest、url、sha256。支持本地和公开 HTTPS 源；同进程 JavaScript 扩展不再兼容。

## 数据与迁移

state.json 升级为 schema 2。迁移前保存 state.before-framework-v2.json；旧设置、人设、绑定和聊天历史保留，旧高权限 QQ 会话取消并归档。旧 JavaScript 扩展停用，提示重装声明式版本。重启取消未完成任务，不从持久化文本重新创建执行身份；发送中任务标记结果未知。

请求收件箱持久化，处理中重启的请求标记结果未知，不自动重复审批。最近事件仅记录元信息；消息观察索引和发送账本在内存中。临时资源在重启时清理。

Token 使用 DSH 凭据服务 DSH_ONEBOT_ACCESS_TOKEN，不写入插件市场包或回显。设置 API 复用 DSH 的管理员认证和来源检查。

## 验证与范围

npm test：核心回归与本机模拟网关。framework-ui-smoke.cjs、framework-ui-actions.cjs、framework-integration.cjs 依赖本机 Playwright/Edge，用于 UI 与真实 DSH 模型联调。集成脚本切换到本机模拟网关，结束恢复配置；不要在用户聊天期间随意运行。

没有安装或执行参考项目 Derpyu520/qq-bridge，也没有复用其源码、签名实现或提示词；旧 dsh-qqbot 仍保持卸载。

本版已加入合并转发发送、群文件目录浏览、受限戳一戳、公告和精华查询。尚未实现签名/在线状态、好友赞、群头像、群文件下载等。外部脚本沙箱和通用后台自动化也未实现，不会作为已完成能力开放。

## 0.3.0 功能包开发流程

插件管理增加独立设置页、版本依赖、设置历史、配置迁移与实际包回滚。声明式包保留当前及最近三个历史版本；升级和回滚后停用，需确认后启用。原生包由 DSH 管理宿主代码版本。

新增内置原生包“群成员动态”，默认停用、欢迎关闭，记录范围需单独选择。记录保留 1–90 天、20–250 条，不存聊天正文，支持分页与 CSV。AI 查询只允许主人，仍需单独授权。自动欢迎是有限事件规则，不借用主人执行身份。

原生 SDK 提供 settings、getScope、storage.update、automaticReply、输入拒绝、回调期限和单包故障隔离。完整字段、迁移示例与信任边界见项目内部文档；联合验收说明见项目内部文档。83 项自动测试及实际页面/本地模拟网关联调已通过，真实 QQ 写操作待联合验收。

0.3.1 调整聊天与权限交互，修复内置开关反馈，并支持其他用户的安全查询共享。详细行为与信任边界见 项目内部文档；实际模型和界面联调记录见项目 data/phase3-integration.json。

## 0.4.0 输入与群聊

所有需要好友/群目标的主要设置复用可搜索选择器，仍可手动填写。群聊支持仅被叫、适度参与、逐条回复；适度参与默认 10%、30 秒冷却、每群每分钟两次随机触发，随机参与不执行工具。私聊保留正常回复。

图片以真实图片块送入 DSH，文本模型回退 OCR；语音用 NapCat 原消息转写，文件原件通过 DSH 会话级 receipt 保存并提取 TXT/DOCX/PDF 等正文；视频附加原件并抽前十五秒最多三帧，不转写视频音轨。Node 至少22.13，视频抽帧需要预装 ffmpeg。大小、页数、时间和身份限制见 项目内部文档。

## 0.6.1：自然分条

新增 natural 分条方式：短聊天的单次换行发送为不同 QQ 气泡，列表和代码不按每行拆开。保留按空行分段、按字数和整段发送；超过整轮条数时仅合并尾部，不把整轮重新合成一个气泡。已用工具发送的消息仍占用同一轮预算；戳一戳保持单条。

## 0.6.2：连续交谈与超时取消

续聊窗口默认 120 秒、8 轮，实际回复后滑动延长，单次最长 10 分钟；多人独立、支持戳一戳后的文字、首次回答期间补充及确认的工具发送。注意力元数据可持久化，不携带执行授权。修复 agent.cancel 返回 void 时超时回调导致 DSH 退出的问题。详见 项目内部文档。


## 0.7.0：独立戳一戳包与统一卸载

戳一戳策略移入 src/builtins/poke/，支持 AI/固定文字、受控回戳、AI 零工具决策、冷却与范围选择；AI 聊天关闭时仍可固定回应。默认不自动回戳，需显式许可并启用核心动作。

所有内置、市场和原生包使用两步卸载确认，默认保留配置，也可按清单删除所属配置；代码目录、人设正文及业务记录保留。重装先保持停用，市场本地重装重新检查完整性。172 项测试和真实 DSH/模拟 OneBot 联调通过。步骤和清理边界见 项目内部文档。


## 0.8.0：多主人、语义交流与表达偏好

主人设置支持多个 QQ 和好友选择；身份检查统一覆盖管理、事件和最终执行权限。未 @ 群消息先判断交流对象，续聊不再因主人发言而自动接话；明确叫她与随机参与分别处理，判断使用零工具并限制用量。动作描写、语气词分别支持自然表达、关闭及按轮概率允许，保留完整括号或去掉完整动作片段。192 项测试与真实 DSH/模拟 OneBot 六项联合检查通过；步骤见 项目内部文档。
