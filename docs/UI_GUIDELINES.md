# UI 规范

新增页面必须先阅读本文。主 UI 是「夜航控制台」：暖白、低饱和、克制、信息密度高。

## 1. 原则

- 先内容、后装饰；没有实际用途的线条、网格、渐变、光晕、毛玻璃一律不加。
- 一个页面只使用一套组件和一套主题变量。
- 数字、ID、时间用等宽字体；正文用系统无衬线；衬线只作品牌/英文短句。
- 状态必须可读：在线/离线、已启用/已停用、成功/失败不能只靠颜色。
- 页面必须能长时间阅读，避免大面积纯黑、强对比和装饰动画。

## 2. 颜色与字体

在 `src/web/public/app.css` 的 `:root` 中定义，不要在页面里写死颜色：

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#f5f1e8` | 页面底色 |
| `--panel` | `#fffdf8` | 卡片/侧栏 |
| `--text` | `#1c1812` | 主文字 |
| `--muted` | `#60584c` | 次要文字 |
| `--faint` | `#8b8173` | 辅助信息 |
| `--accent` | `#9c5f20` | 强调/焦点 |
| `--accent-2` | `#3f6d78` | 第二信息 |
| `--ok` / `--warn` / `--danger` | `#2f7652` / `#96621c` / `#ad3a2c` | 状态 |

- 正文 12–13.5px，行高 1.6–1.8；页面标题 26px 左右；卡片标题 14.5px。
- 不引入外部字体；使用 `Segoe UI` / 微软雅黑 / 系统字体。
- 不使用 Emoji 当图标；使用 `app.js` 的 `ICONS` SVG。

## 3. 布局

- 桌面：248px 固定侧栏 + 主内容 `max-width: 1220px`。
- 侧栏：品牌 → 编号主导航 → `功能包` 分组 → 底部状态/版本/退出。
- 主导航编号 `01`…`08`；功能包子项 `06.1`…`06.4`。
- 顶栏：面包屑、时钟、在线 pill、刷新、退出；不放大标题。
- 内容区：页面标题 → 统计条 → 卡片/分栏；卡片间距 16–18px。
- 1024px 以下：统计两列、分栏单列、隐藏时钟。
- 860px 以下：侧栏变顶部横向导航；表单单列；弹窗留 10px 边距。
- 560px 以下：统计单列、表情网格两列。
- 不允许水平溢出；表格用 `.table-wrap` 横向滚动。

## 4. 页面标题

```js
pageHeader(title, description, [statePill(...), pill(...)], [button(...)])
```

- 标题只写页面名，不写“管理”“设置”等重复词。
- 描述一句话说明真实数据来源。
- 状态 pill 不超过 3 个；长错误放正文 notice，不塞进 pill。

## 5. 表单

- 使用 `.form-grid`，默认两列；长文本/开关用 `.span-2`。
- 每个控件有 `field(label, control, hint)`。
- 数字输入必须设置 `min`/`max`，保存时 `Number()` 并重新校验。
- 开关用 `toggle(label, checked, onChange, help)`。
- 保存条用 `savebar(note, onSave)`；保存中禁用按钮，失败 toast 并保留草稿。
- 配置重置必须从服务端最新值恢复，不能凭空写默认值。

## 6. 卡片与统计

- 卡片：白底、1px `--line`、12px 圆角、20px 内边距；不加阴影/渐变。
- 统计条：4 列，数字等宽 21px，标签 10.5px；窄屏两列/单列。
- 卡片标题下描述只写数据来源和操作后果。
- 不要给每个卡片加无意义编号；插件页面已有清晰标题时不再重复编号。

## 7. 表格、列表、空状态

- 表格：`.table-wrap > table.table`，表头 10px 灰字，行 9–11px 内边距。
- 空状态：`.empty` 虚线框，说明“为什么空”和下一步。
- 加载：`stateBox('正在读取…', '数据来源…')`；不要用假骨架数字。
- 错误：`stateBox('…失败', error, 重试按钮)`；错误原文截断到 300 字。
- 无权限：明确说明需要管理登录或动作授权，不显示可点击的假按钮。

## 8. 弹窗

- `openModal(title, subtitle, body, actions)`。
- 宽度 ≤680px；body 可滚动；底部操作右对齐。
- 破坏性操作使用 `confirmDialog`，按钮文案写“删除/清空”，不能只写“确定”。
- 秘密正文只在弹窗局部变量中；关闭即丢弃，不写入全局状态。
- 弹窗打开时按 Esc 不自动提交；点击遮罩只关闭，不执行操作。

## 9. 图表

- 星图：Three.js/WebGL 真实 3D，节点来自真实记忆；连线必须标注共享标签/相似度等依据。允许星图区域使用深色空间背景、粒子、景深和缓慢动态，但不能把整个控制台改成暗色；不支持 WebGL 时必须提供明确降级提示。
- 星图属性必须有数据含义：大小=重要度，颜色=范围，亮度=最近更新，连线颜色/线宽=关系类型/强度。
- 星图必须提供暂停动态、重置视角、搜索定位、范围筛选、侧栏详情；离开页面时销毁 RAF、ResizeObserver 和监听器。
- 曲线：SVG，明确图例“理论保持度”和“真实复习记录”；不能用理论值冒充实际测量。
- 其他图表颜色只用 `--accent`/`--accent-2`/`--line`；不用大面积填充。
- 没有数据时显示空状态，不画一条假曲线。

## 10. 交互与可访问性

- 所有按钮 `type="button"`（表单提交除外）。
- 图标按钮必须有 `aria-label`；当前导航用 `aria-current="page"`。
- 开关保留原生 checkbox 的键盘行为。
- 焦点使用 `:focus-visible` 可见环。
- 页面切换关闭弹窗；退出登录清空页面缓存和前端秘密状态。
- 不使用自动播放动画；`prefers-reduced-motion` 下关闭过渡。

## 11. 新增页面必须复用的组件

`app.js` 中已有：`pageHeader`、`card`、`button`、`field`、`textInput`、`numberInput`、`textArea`、`select`、`toggle`、`stat`、`pill`、`stateBox`、`pager`、`tabs`、`openModal`、`confirmDialog`、`savebar`、`dateText`、`bytesText`、`tagList`。

不要复制一套新的按钮/开关/弹窗 CSS。需要新组件时先加到 `app.css` 的通用区，再在页面中使用。

## 12. 禁止项

- 渐变背景、发光边框、毛玻璃、背景网格、粒子/星空特效。
- 每秒跳动的假统计、随机在线状态、随机活动记录。
- 用 Emoji 代替正式图标。
- 为单个插件另起主题色或引入第二套 UI 库。
- 把未实现的功能做成可点击按钮；应显示“暂不可用/接口未提供”。
