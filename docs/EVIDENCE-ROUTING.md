# 群聊受话人与来源修复

- 开启意图识别时，@ 他人和引用他人也进入判断；监听范围与身份校验不变。
- 当前消息、引用与持久化背景保留 @ QQ；戳一戳保留发起者、目标和时间。
- 判断器增加 addressee、antecedentId、correction；旧格式仍兼容。member/unknown 不允许直接当作 addressed 回答。
- 已启用的当前群基础查询（状态、群资料、成员、消息、历史）可供 chat/context 使用，明确拒绝仍优先。不会开放跨群、私聊、管理或电脑操作。
- 事实来源与纠正处理加入核心提示；这不是通用的事实验证器，仍需真实群聊观察。
- 发送工具声明 type/data 结构；成功或已受理的发送抑制最终回复二次发送。模型应将一轮需要发送的内容通过发送工具完成。
- 联网查资料包可按独立授权搜索公开网页和图片；图片发送只接受当前用户刚搜索到的短期编号，并受底层图片发送权限约束。未改变每轮群聊会话重建策略；未开放任意本机工具。
- 历史背景里已经丢失的 @ 无法凭空恢复，新消息生效；可通过仍可查询的原消息核实。

验证：node --test tests/*.test.js。重点包括 @ 他人纠正、短句受话人、持久化元数据、真实 @、去重和普通用户越权拒绝。
