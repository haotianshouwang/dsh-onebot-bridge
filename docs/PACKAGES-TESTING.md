# QQ 框架 0.7.0：模块化与统一卸载验收

日期：2026-10-30。入口：DSH → 设置 → QQ 框架 → 插件。

## 本次交付

戳一戳互动成为独立内置包，与 AI 聊天、人设、入群欢迎、市场并列。策略代码位于 src/builtins/poke/index.js；事件回戳的受控执行位于 src/core/event-actions.js。核心保留 OneBot 对接、主人身份、受限 Agent 和权限检查。AI 聊天关闭后仍能使用固定文字回应、受控回戳。

内置包、市场声明式扩展、已注册可信原生包全部接入 src/core/uninstall.js 的同一卸载流程。代码从本项目现有接口自行实现，没有拷贝参考项目源码或提示词。

人设功能代码仍在 src/builtins/persona/；用户的人设名称和提示词保存在 data/dsh-onebot-bridge/state.json，不是每个人设一个代码目录。AI 聊天仍有部分编排在 session/router.js；本版不宣称所有业务已完全解耦。

## 卸载规则

1. 点击“卸载包”，选择“保留配置”（默认）或“删除配置”。此时不卸载。
2. 下一步展示名称、版本、配置处理方式、清理项、保留项，再点击“确认卸载”。
3. 任一步取消或按 Esc 均不修改配置、不停止插件。确认后停用该包并撤销旧任务的继续执行资格。
4. 两步之间配置或版本变化会使确认失效；确认票据有效期两分钟、只能使用一次。有依赖的包先处理依赖，不能绕过检查。
5. 所有包的代码文件和安装记录保留。卸载后显示“重新安装”；重装先保持停用，检查设置后再启用。市场重装使用保留的本地文件，并重新核对文件完整性。
6. 外部原生包仅移除 QQ 框架中的功能注册，DSH 宿主代码由 DSH 自身管理；界面会说明这一点。

“删除配置”的具体边界：

| 包类型 | 清理内容 | 保留内容 |
| --- | --- | --- |
| 人设 | 默认选择、聊天绑定和该包设置历史 | 人设名称、完整提示词、聊天记录 |
| AI 聊天 | 聊天节奏、输出样式和背景等所属配置 | 聊天接收范围、主人权限、聊天记录 |
| 戳一戳 / 入群欢迎 | 该包设置与设置历史，恢复默认值 | 代码、聊天记录、其他包配置 |
| 市场内置包 | 自定义市场源及所属设置 | 已有插件文件和记录 |
| 市场扩展 / 可信原生包 | 该包配置、作用范围、自动化许可、设置历史、历史版本配置、该包专属工具开关及授权 | 代码、业务存储、其他包设置、主人身份和 OneBot 凭据 |

保留配置卸载会保留该包的设置。删除配置后，旧设置历史也不能恢复被清理的配置；重新安装不会自动重新启用或扩大权限。人设正文、聊天内容、插件业务记录均不会因“删除配置”而静默删除。

## 戳一戳设置

展开“戳一戳互动 → 互动设置”。可选择文字回应、回戳、文字加回戳、让 AI 判断；文字可使用当前人设或固定短句。还可设置概率、冷却、是否续聊、私聊/群聊范围，以及复用好友和群选择器。

默认使用 AI 文字回应，自动回戳关闭。AI 聊天停用时使用固定短句，不调用模型。AI 判断使用零工具的受限决策，只能决定本次是否回应和回戳，不能借此调用服务器、电脑或通用工具。无效决策退回固定文字。

自动回戳需同时满足：包已启用、允许自动回戳、核心 qq.poke 动作已启用、NapCat 网关支持、当前聊天在监听及回复范围内。只能回戳本次真正戳机器人的人；不能指定其他人。每人每分钟最多一次，与手动受限工具共用回戳额度；结果未知不自动重发。普通用户可按上述已明确配置的事件规则获得回戳，不因此取得工具权限。

## 建议按顺序测试

1. 刷新 DSH 设置，找到独立“戳一戳互动”卡片。关闭 AI 聊天，选固定文字模式并保存；在已允许群中戳机器人，应只回复短句。恢复 AI 聊天后测试人设回应。
2. 如需回戳：开启自动回戳及核心 qq.poke，选择回戳或文字加回戳。请普通群成员戳机器人，应只回戳该成员；连续戳不应连续回戳。群和好友范围外不回应。完成后按需关闭自动回戳。
3. 测试“让 AI 判断”：允许不说话、只文字、只回戳或两者；不应把 JSON 或内部协议发进 QQ。是否回戳由本轮决策决定，不保证每次触发。
4. 关闭“戳一戳互动”，戳机器人应无该包回应；AI 聊天与主人管理仍可用。恢复开关。
5. 选择一个不重要的包卸载，在第一步取消；再进入第二步取消；还可用 Esc。检查开关、配置和功能均保持原状。
6. 给该包填一项测试设置，按“保留配置”确认卸载。确认该包消失于可用功能、源文件保留；点重新安装，应先停用、测试设置保留，再手动启用。
7. 用测试包按“删除配置”确认卸载，核对第二步清单；重装后应为默认配置/空授权，旧设置历史不能恢复清理项。请勿为了验收删除正在使用的人设绑定。
8. 分别在内置包、市场扩展和“群成员动态”等可信原生包上打开确认窗口，检查流程一致。若某原生包由外部 DSH 模块提供，应展示宿主说明。
9. 开启第二步后在另一页面保存设置，再确认旧窗口，应提示确认失效；等待超过两分钟也需重新开始。
10. 最后确认原有人设、主人 QQ、群范围和核心权限均保留，QQ 聊天不会得到电脑或服务器操作能力。

本机真实 QQ 互动仍请按以上步骤实测；已完成的联调没有对真实 QQ 发送消息、回戳或改资料。
